# Telegram-бот «Лёша»

Персонажный бот с краткосрочной памятью (txt), долгосрочной (MySQL) и ответами через ChatGPT в образе Лёши.

## Требования

- Node.js 18+
- MySQL (схема в `db/schema.sql`)
- Токены: Telegram Bot, OpenAI API

## Установка

```bash
npm install
```

Создайте `.env` (или скопируйте `.env.example`):

- `BOT_TOKEN` — токен бота от @BotFather
- `OPENAI_API_KEY` — ключ OpenAI
- `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` — доступ к MySQL

## База данных

При первом запуске приложение само создаёт все таблицы в БД (users, messages, user_facts, friend_list, prompts, character_quotes), если их ещё нет, и загружает промпты из папки `prompts/` в таблицу `prompts`. Ручной запуск миграций не нужен — достаточно указать в `.env` доступ к MySQL и запустить `npm start`.

## Запуск

```bash
npm start
```

Бот работает в режиме long polling. Отвечает **не на каждое** сообщение, а только если:
- к нему обращаются (Лёша, леша, ответ на его сообщение) **или**
- участие в диалоге подходит характеру (решает модель по последним репликам).

### Беседы (группы)

Чтобы бот **получал все сообщения** из беседы (группы), в Telegram нужно **отключить режим конфиденциальности** (Privacy mode):

1. Открой [@BotFather](https://t.me/BotFather).
2. Отправь `/mybots` → выбери своего бота.
3. **Bot Settings** → **Group Privacy** → **Turn off**.

Иначе Telegram присылает боту только команды (`/start`), ответы на сообщения бота и упоминания (@бот). Обычные реплики в чате бот не получит и не «увидит».

При старте промпты из папки `prompts/*.txt` синхронизируются в таблицу `prompts` (по полю `name`); дальше все промпты берутся из БД. Цитаты о Лёше и о @christofferlacour из диалогов сохраняются в `character_quotes` и подмешиваются в контекст характера (самообучение).

## Структура проекта

- `data/chat_memory/` — краткосрочная память по чатам (`chat_<chat_id>.txt`, последние ~28 реплик)
- `data/logs/` — логи (при необходимости)
- `prompts/` — исходные промпты (при старте копируются в БД, таблица `prompts`; по `name` подгружаются в LLM)
- `db/` — схема, сиды, миграции; таблицы `prompts`, `character_quotes` для промптов и цитат о Лёше/christofferlacour
- `services/telegram/` — логика бота
- `services/memory/` — работа с txt-памятью
- `services/llm/` — сборка контекста и вызов OpenAI
- `config/` — роли и настройки

## Роли (config/roles.md)

В БД у пользователей есть роли: `lover`, `friend`, `human`, `ai_suspect`, `ex`, `enemy`. Они влияют на формирование социального контекста для Лёши.
